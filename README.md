# 💧 JalDarpan - Smart Water Supply Tracker

> India's first citizen-powered water transparency platform for Solapur Municipal Corporation


## 🎯 Problem Statement

Urban water supply in India is **highly unpredictable**. Municipal schedules are unreliable, citizens have **zero real-time visibility**, and there's **no accountability mechanism** for water departments.

**Impact:** Citizens waste time waiting, plan disruptions, and daily frustration across millions of households.

---

## 💡 Our Solution

**JalDarpan**  - A real-time water supply tracking platform that:

- 🗺️ **Live Map** - Color-coded ward status (Green/Yellow/Red)
- 👥 **Crowd Reports** - Citizens report water status via GPS-tagged submissions
- 📊 **Accuracy Score** - Track municipal performance per ward
- 🔮 **ML Predictions** - Forecast delays before they happen
- 🔔 **Smart Alerts** - Instant notifications for outages/restorations
- 🛡️ **Admin Dashboard** - Municipal control panel for transparency

---

## 🚀 Key Features

### For Citizens:
✅ Real-time ward-level water supply status  
✅ Next supply time predictions with confidence scores  
✅ One-tap reporting (Water Running / No Water)  
✅ Push notifications for supply changes  
✅ Municipal accountability tracking  

### For Administrators:
✅ Live ward status control panel  
✅ Broadcast alerts to citizens  
✅ Performance analytics per zone  
✅ Multi-city management dashboard

## 🎨 Tech Stack

| Layer | Technology |
|-------|-----------|
| **Frontend** | React.js, Tailwind CSS |
| **Backend** | Firebase Realtime Database |
| **Authentication** | Firebase Auth (Email + Google OAuth) |
| **Maps** | Leaflet.js + OpenStreetMap |
| **ML Predictions** | scikit-learn (Python/Flask API) |
| **Hosting** | Vercel (Frontend) + Render (Backend) |
